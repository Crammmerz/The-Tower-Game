🏰 The Tower Game
A Godot-powered survival game where you are reincarnated as a tower in a collapsing world.  
Your only purpose: withstand endless waves of slimes as humanity’s last defense.

🌌 Story Premise
The world teeters on the brink of destruction.
One soul is reborn—not as a hero, but as a tower.
Now, surrounded by hordes of relentless slimes, survival is the only path forward.

🎮 Game Features
Infinity Mode Only: No levels, no endings—just pure survival against endless waves.

Horde Mechanics: Slimes spawn dynamically, scaling in difficulty as time progresses.

Modular & Scalable Architecture: Built with clean OOP principles for easy expansion.

Signal-Driven Flow: Managers communicate via signals for clarity and maintainability.

Progression System: Gentle XP scaling (multiplier ~1.2) ensures balanced long-term play.

⚙️ Technical Design
Godot Engine (latest version)

Managers:

WaveManager – controls slime spawning logic

ProgressionManager – handles XP and leveling

PlayerStateManager – tracks tower health, upgrades, and states

GameManager – orchestrates overall game flow

UIManager – modular UI updates via signals

AudioManager – scalable sound system

OOP Principles: Separation of concerns, modular managers, and clear naming conventions.

Scalability: Designed for future modes, abilities, and enemy types without rewriting core systems.
